# Dolphin Context Menu Manager

A lightweight GUI application for creating and managing custom right-click
actions in KDE Dolphin.

It can create, edit, and remove Dolphin right click menu options without requiring you to edit `.desktop` files by hand.

## Build

Requires CMake 3.21+, a C++20 compiler, and Qt 6.5 or newer.

```bash
./build.sh
./build.sh run
```

Install it for the current user with:

```bash
./build.sh install
```
